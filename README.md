## 📌 Overview

**BOT KEY** is an intelligent AI chatbot designed to provide answers in a smarter, more flexible, and interactive way.  
Unlike traditional chatbots that generate only one response, BOT KEY enables users to explore multiple perspectives for the same question.

The chatbot supports both **single-response** and **multi-response** modes, allowing users to receive answers in different formats such as:

- Simple explanation
- Detailed answer
- Creative response
- Step-by-step guidance

BOT KEY is developed to improve learning, exploration, and AI interaction through a clean and user-friendly experience.

## 🧠 Multi-Response System

BOT KEY can generate different styles of responses for the same question.

| Response Style | Description |
|---|---|
| Simple | Easy and beginner-friendly explanation |
| Detailed | In-depth explanation with more clarity |
| Creative | Unique and imaginative answer |
| Step-by-Step | Structured guidance with clear steps |

This approach helps users understand concepts from different perspectives instead of relying on only one answer.

---

## ⚙️ How It Works

1. Enter your question in the chatbot interface.
2. Choose your preferred response mode:
   - Single Response
   - Multi-Response
3. BOT KEY processes the query using AI.
4. Responses are generated based on the selected mode.
5. Users can compare and explore multiple answer styles.
