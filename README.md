# BOT KEY

BOT KEY is an AI chatbot that helps users get answers in a simple and flexible way.
It can respond like a normal assistant or generate multiple answers for the same question.

The chatbot allows users to switch between single response and multi-response modes.
In multi-response mode, it gives different types of answers such as simple, detailed, creative, and step-by-step.

Users can also interact using text, voice, and file input.
The system is designed to feel smooth, fast, and easy to use without changing the interface.

This project focuses on improving how users explore answers by giving multiple perspectives instead of just one.

---

### Features

* Single response mode
* Multi-response mode (multiple answer styles)
* Voice input support
* File input support
* Clean and responsive chat interface

---

### How it works

Enter your question and the chatbot will generate a response.
You can enable multi-response mode to see different types of answers for better understanding.

---

### Note

This project is built to enhance learning and exploration by providing multiple ways to understand a single question.
